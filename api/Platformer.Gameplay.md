# <a id="Platformer_Gameplay"></a> Namespace Platformer.Gameplay

### Classes

 [EnablePlayerInput](Platformer.Gameplay.EnablePlayerInput.md)

This event is fired when user input should be enabled.

 [EnemyDeath](Platformer.Gameplay.EnemyDeath.md)

Fired when the health component on an enemy has a hitpoint value of  0.

 [HealthIsZero](Platformer.Gameplay.HealthIsZero.md)

Fired when the player health reaches 0. This usually would result in a 
PlayerDeath event.

 [PlayerDeath](Platformer.Gameplay.PlayerDeath.md)

Fired when the player has died.

 [PlayerEnemyCollision](Platformer.Gameplay.PlayerEnemyCollision.md)

Fired when a Player collides with an Enemy.

 [PlayerEnteredDeathZone](Platformer.Gameplay.PlayerEnteredDeathZone.md)

Fired when a player enters a trigger with a DeathZone component.

 [PlayerEnteredVictoryZone](Platformer.Gameplay.PlayerEnteredVictoryZone.md)

This event is triggered when the player character enters a trigger with a VictoryZone component.

 [PlayerJumped](Platformer.Gameplay.PlayerJumped.md)

Fired when the player performs a Jump.

 [PlayerLanded](Platformer.Gameplay.PlayerLanded.md)

Fired when the player character lands after being airborne.

 [PlayerSpawn](Platformer.Gameplay.PlayerSpawn.md)

Fired when the player is spawned after dying.

 [PlayerStopJump](Platformer.Gameplay.PlayerStopJump.md)

Fired when the Jump Input is deactivated by the user, cancelling the upward velocity of the jump.

 [PlayerTokenCollision](Platformer.Gameplay.PlayerTokenCollision.md)

Fired when a player collides with a token.
